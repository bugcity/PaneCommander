# PaneCommander

Windows 11向けの、キーボード操作を中心とした2ペインファイルマネージャーです。C# / .NET 10 / WPFで実装しています。

## 主な機能

- 左右ペイン、複数タブ、お気に入り、作業状態の保存と復元
- 開いているフォルダーの変更を自動反映（ダウンロード・追加・削除・名前変更・サイズ更新）
- コピー・移動・名前変更・ファイル作成・複数階層のフォルダー作成
- ローカルフォルダーとUNC共有パスへのアクセス
- 詳細一覧の列設定、名前フィルターと一致部分の強調
- 名前列を手動で広げた場合も、更新日時→サイズ→File Age→種類の順で列を自動省略。幅を戻すと再表示
- Windowsのフォルダー・ファイル種類別アイコン（関連付けに従う表示）
- タイトルバーの「お気に入り」「更新」「設定」ボタン
- 操作中・完了・中止・エラーのメッセージを対象パネル下部に表示。件数・読み込み状態・監視警告も同じ欄で確認でき、長い場合はマウスを重ねると全文を確認
- タイトルバーは現在のフォルダー名またはパスと操作ボタンを表示。ドラッグ移動・ダブルクリックで最大化／復元でき、DWMの標準ウィンドウ枠を使用
- 隠しファイルと「.」で始まるファイルの個別表示設定（初期は両方非表示）
- 更新日時からの経過時間を色で示すFile Age列
- Windows Shellメニュー、既定アプリで開く、Shell Edit、読み取り専用テキストプレビュー
- 実際のキーボードフォーカスに合わせたペイン・選択行の表示
- ACTIVEと枠線で操作対象のペインを表示。アプリが非アクティブでも対象表示を維持し、パネルの余白クリックでその一覧へフォーカスを移動

## ビルド・実行

Windows 11と.NET 10 SDKが必要です。ビルド済みアプリの実行には.NET 10 Desktop Runtimeを使用します。

```powershell
dotnet build PaneCommander.sln -c Release
dotnet run --project src/PaneCommander.App -c Release --no-build
```

設定・お気に入り・セッションは `%LOCALAPPDATA%/PaneCommander/`、ログはその下の `logs/` に保存します。初回起動時は左右ともホームフォルダーを表示します。

開いている各フォルダーをWindowsの変更通知で監視します。表示中の一覧は通知を約300ミリ秒単位でまとめて更新し、選択・スクロール位置・フォーカスを保持します。表示していないタブは切替時に反映し、同じフォルダーの監視は共有します。無変更時の定期走査は行いません。監視に失敗すると一覧下部へ「自動更新停止」を表示し、Ctrl+Rによる手動更新成功後に再接続を試します。

描画方式はSoftwareOnlyが既定です。設定画面でDefaultへ変更できますが、一部環境でGPU描画時の白画面を確認しており、原因は未確定です。変更は正常終了後の再起動で反映します。

## テスト

```powershell
dotnet test PaneCommander.sln -c Release
```

WPF・Windows Shellを使うテストはWindows上で実行します。シンボリックリンク権限やクリップボードを扱う一部テストには実行条件があり、スキップを合格とは扱いません。UNC実共有のテストは、専用テストフォルダーの作成・削除を許可した共有ルートを `PANECOMMANDER_UNC_TEST_ROOT` に指定した場合だけ実行してください。

## キーバインド

2026-10-19時点の実装に対応します。PaneCommander固有の割当を以下に列挙し、WPF・Windowsの標準操作は別表に示します。キー割当の編集機能はありません。

### メイン画面共通

文字入力欄以外で有効です。対象はACTIVEになっているペインです。入力欄では文字編集を優先し、これらのキーでタブ操作やファイル操作を横取りしません。ダイアログやShellメニューを開いている間は、その画面のキー操作を使用します。

ACTIVEはFキーやファイル操作の対象を示し、タイトルバー・お気に入りへフォーカスを移したときや、別アプリを使っている間も表示します。行の選択色は実際のキーボードフォーカスに従います。パネルの余白やパス表示をクリックすると、操作対象・タイトル・一覧のフォーカスを合わせます。ボタンやフィルター入力欄の操作では、その要素のフォーカスを維持します。

外部へファイルをドラッグ＆ドロップした後は、タイトルバーなどからPaneCommanderを再アクティブ化した時点で、ドラッグ元の一覧の選択・フォーカスを復元します。移動で項目が消えた場合は近くの行、空の場合は一覧自体へ戻します。別のペイン・タブ・入力欄などを明示的に選んだ場合は、その操作を優先します。外部アプリでのドロップ直後にフォーカスを奪い返すことはありません。

一覧の余白を右クリックして「新規作成 → フォルダー」を選ぶと、F7と同じ名前入力ダイアログを開きます。入力を確定してから作成し、キャンセル時は作成しません。作成後はそのフォルダーを選択して一覧へフォーカスを戻します。

ファイル操作の通知は、開始時の対象タブに固定します。途中で左右やタブを切り替えても、別のタブに結果を表示しません。通常の操作は操作元、一覧へのドロップはドロップ先に表示します。タイトルバーに操作通知は表示しません。

| メッセージ | 表示を終える条件 |
|---|---|
| 件数・一覧の基本状態 | 常時表示し、読み込み結果に合わせて更新 |
| 読み込み中・ファイル操作中 | 処理終了時に結果へ置換 |
| 正常完了・ファイル起動成功 | 対象タブを表示し、アプリがアクティブな時間を合計5秒経過すると消去 |
| 操作中止・一部完了・操作エラー | 自動消去せず、下部の×または一覧でEscを押して確認、次の操作、フォルダー移動で消去 |
| 監視・属性取得などの警告 | 原因が解消するまで表示。操作通知の×や期限では消去しない |

正常完了の表示時間は、別タブの表示中・アプリが非アクティブ・最小化中には進めません。左右のフォーカス切替だけでは通知を消しません。同じフォルダーの再取得・自動更新で5秒の期限を延長しません。次の操作は旧通知を上書きし、フォルダー移動は旧通知をクリアします。Escは範囲選択の取り消し・フィルター解除を優先し、その後に通知を閉じます。処理中の通知は確認操作では消せません。

| キー | 動作・条件 |
|---|---|
| Ctrl+T | 現在のフォルダー・表示オプションを継承したタブをアクティブ側に追加 |
| Ctrl+W | アクティブ側の現在タブを閉じる。最後の1枚は閉じない |
| Ctrl+R | アクティブ側の現在フォルダーを更新 |
| Ctrl+D | 現在フォルダーをお気に入りへ登録。表示名の入力画面を開く |
| Ctrl+H | 現在タブの「隠しファイルを表示」を切替。「.ファイルを表示」は変更しない |
| Shift+← / Shift+→ | アクティブペインの前／次のタブへ切替。端では循環し、切替先の一覧へフォーカスを戻す。1タブの場合はそのまま。文字入力欄では文字の範囲選択を維持 |
| Ctrl+Shift+← / Ctrl+Shift+→ | アクティブペインの選択中のタブを左／右へ1つ移動して並べ替え。端では止まり、選択タブとファイルの選択を保持して一覧へフォーカスを戻す。文字入力欄では実行しない |
| F1 | ヘルプ：未実装のため無効 |
| F2 | ユーザー：未実装のため無効。名前変更はShift+F6を使用 |
| F3 | 選択した1ファイルを読み取り専用テキストプレビューで表示。1 MiB以下、UTF-8またはBOM付きUTF-16/32が対象 |
| F4 | 選択した通常ファイル1件をWindows ShellのEditで編集。ディレクトリ・リンクは対象外。Edit未登録時は通知し、Openへ代替しない |
| F5 | 選択項目をコピー。送り先の初期値は反対側の現在フォルダー。1件選択時は新しい名前も指定可 |
| F6 | 選択項目を移動。送り先の初期値は反対側の現在フォルダー。1件選択時は名前変更も指定可 |
| Shift+F5 | 同じフォルダー内へ名前を明示指定してコピー。複数選択時は各項目の新しい名前を順に指定 |
| Shift+F6 | 選択した1項目を同じフォルダー内で名前変更 |
| F7 | 現在フォルダーにフォルダーを作成。`親\子\孫`、`親/子/孫`のような複数階層に対応。既存のフォルダーは利用し、不足分を作成 |
| Shift+F7 | 現在フォルダーに空のファイルを新規作成。ファイル名と拡張子を入力し、Enterで確定、Escで中止。同名ファイル・フォルダーは上書きしない。作成後は一覧で新規ファイルを選択（表示条件で隠れる項目はその条件を維持） |
| F8 | 選択項目をごみ箱へ移動。UNC・リンクを含む対象など、対応外の条件では中止し、完全削除へ自動で切り替えない |
| F9 | メニュー：未実装のため無効。ShellメニューはShift+F10またはAppsキーを使用 |
| F10 | アプリを終了。作業状態を保存できない場合は終了を中止 |
| Shift+F10 | 選択項目のWindows Shellメニューを開く。選択なしの場合は現在フォルダーの背景メニュー |

コピー・移動・削除は選択項目がある場合に有効です。操作中は競合するファイル操作を無効にします。Fキーや下部ボタンの操作後は一覧でのキーボード操作を続けられます。F11/F12にはアプリ専用の割当はありません。

下部のファンクションボタンはShiftを押している間、`⇧F5 別名コピー`・`⇧F6 名前変更`・`⇧F7 ファイル作成`・`⇧F10 メニュー`へ切り替わります。割当のない組合せは「—」で無効表示にします。Shiftを離すかウィンドウが非アクティブになると通常表示へ戻ります。選択なし・フォルダー選択・複数選択・読み込み中・ファイル操作中などの条件で実行できない操作は淡色にし、キー入力も同じ条件で無効にします。ボタン自身へキーボードフォーカスは移しません。

### ファイル一覧にフォーカスがあるとき

| キー | 動作・条件 |
|---|---|
| Tab / Shift+Tab | 左右のアクティブペインを切替え、切替先の一覧へフォーカスを移す |
| Enter | 選択したフォルダーへ移動、またはファイルを既定アプリで開く。複数選択時の一括Openではない |
| Backspace | 親フォルダーへ移動し、今いたフォルダーの行を選択・画面内に表示してフォーカスを戻す。行が非表示の場合は先頭の表示行、空の場合は一覧自体へ。ドライブ・UNC共有のルートでは止まる。キーボードの↑とは別の操作 |
| Alt+← / Alt+→ | 現在タブの履歴を戻る／進む |
| Insert | フォーカス行の選択を反転。選択解除後も行のフォーカスを維持するため、もう一度押すと再選択できる |
| Ctrl+C | 選択したファイル・フォルダーをWindows Shellのクリップボードへコピー |
| Ctrl+X | 選択したファイル・フォルダーを切り取り。移動は貼り付け時に実行 |
| Ctrl+V | クリップボードのファイル・フォルダーを現在のペインの現在フォルダーへ貼り付け。コピー／切り取りの転送方式に従う |
| Ctrl+A | 現在表示されている一覧の全項目を選択 |
| Delete | 選択項目をごみ箱へ移動（F8と同じ制限）。削除後は次の行、末尾なら前の行を選択してフォーカスを戻す。空の場合は一覧へ戻す。F8・Shift+Deleteも同様 |
| Shift+Delete | 確認後に完全削除。ごみ箱へは移動しない |
| `/`（スラッシュキー）またはテンキーの`÷` | 名前フィルターの入力欄を開いてフォーカスを移す。修飾キーなしで使用。配列上のキーに対応し、Shiftを伴う文字入力とは区別 |
| Esc | 範囲選択中は取り消し。名前フィルターが開いている／条件がある場合は解除。それ以外では完了・中止・エラーの操作通知を閉じる（処理中や警告は消さない） |
| Apps（メニューキー） | Shift+F10と同じWindows Shellメニューを開く |

F7の作成先は現在フォルダーからの相対パスです。絶対パス、`..`、空の中間階層、不正な名前は拒否します。途中に同名ファイルやリンクがある場合も中止します。途中で権限・通信エラー等が起きた場合、すでに作成した親フォルダーが残ることがあります。

Ctrl+C/X/Vはファイル一覧にフォーカスがある場合だけファイル操作になります。入力欄では文字編集を維持します。テキスト・画像だけのクリップボードからファイルは作成しません。リンクを含む転送は既存のShellメニューと同じ制限に従い、F5/F6を使用します。貼り付け先は反対側ではなく、操作中のペインです。

### 名前フィルターの入力欄

| キー | 動作 |
|---|---|
| Enter | 条件を保持したままファイル一覧へ戻る |
| Esc | 条件を消し、フィルター入力欄を閉じて一覧へ戻る |
| その他の文字編集キー | 通常のテキスト入力。Enter/Esc以外のファイル操作ショートカットは実行しない |

### 表示オプションのチェックリスト

ツール領域の「表示オプション ▾」から開きます。

| キー | 動作 |
|---|---|
| Tab / Shift+Tab | 「隠しファイルを表示」「.ファイルを表示」の間を循環してフォーカス移動 |
| Space | フォーカスのある項目のチェックを切替 |
| Enter / Esc | チェックリストを閉じ、ファイル一覧へ戻る |

変更はチェックした時点で反映され、Escでも変更内容は戻りません。外側をクリックしても閉じます。隠しファイルはHidden属性がある項目、.ファイルは「.」で始まりHidden属性がない項目です。どちらも初期は非表示で、タブごとに保存・復元します。

### お気に入り

| キー | 動作 |
|---|---|
| ↑ / ↓ | お気に入り一覧内で選択を移動（標準操作） |
| Enter | 選択したお気に入りを現在のアクティブペインで開き、読み込み後に一覧の先頭表示行へフォーカスを移す。空の場合は一覧自体へ |

お気に入り登録自体の削除・並べ替え・表示名変更には専用のキー割当はありません。サイドバーの「解除」「↑」「↓」「名前」ボタンを使います。メイン画面共通のCtrl+Dはフォルダー登録です。

### ダイアログ・Shellメニュー

| 場面 | キー | 動作 |
|---|---|---|
| 移動／ファイル操作／お気に入り名／設定／カラー編集／Shell名前変更の入力画面 | Enter | 初期設定の実行ボタンを押す（入力が有効な場合）。設定では「保存・適用」 |
| 同上 | Esc | キャンセルして閉じる。設定画面では保存しない |
| 読み取り専用プレビュー | Esc | プレビューを閉じて一覧へ戻る。Enterはファイル操作の実行キーではない |
| 通常のダイアログ・ツール領域 | Tab / Shift+Tab | 次／前の操作要素へフォーカス移動。左右ペインの切替ではない |
| 通常のボタン／チェックボックス | Space | フォーカス中のボタンを押す／チェックを切替（標準操作） |
| Shellメニュー表示中 | ↑ / ↓、← / → | メニュー項目の選択、サブメニューの移動（Windows標準） |
| Shellメニュー表示中 | Enter / Esc | 項目を実行／メニューを閉じる（Windows標準） |
| ウィンドウ共通 | Alt+F4 | アクティブなウィンドウを閉じる（Windows標準）。メイン画面では作業状態の保存を伴う |

### 一覧・タブ・テキストの標準操作

以下は独自割当を追加していないWPF標準の操作です。フォーカス位置と選択モードに従います。

| 場面 | キー | 動作 |
|---|---|---|
| ファイル一覧 | ↑ / ↓ | 前／次の行へ移動 |
| ファイル一覧 | Home / End、PageUp / PageDown | 先頭／末尾、前／次のページへ移動 |
| ファイル一覧 | Ctrl+A | 全項目を選択 |
| ファイル一覧 | Shift+↑ / Shift+↓、Shift+Home / Shift+End、Shift+PageUp / Shift+PageDown | 連続した範囲を選択。Shift+← / Shift+→はタブ切替に使用 |
| ファイル一覧 | Ctrl+移動キー | 既存の選択を保ってフォーカスを移動 |
| ファイル一覧の行 | Ctrl+Space | フォーカス行の選択を反転 |
| ペイン内のタブ領域・その内容 | Ctrl+Tab / Ctrl+Shift+Tab | 同じペイン内の次／前のタブを選択（左右ペイン切替とは別） |
| タブ見出し | ← / →、Home / End | タブの選択を移動、先頭／末尾のタブを選択 |
| 文字入力欄・プレビュー | Ctrl+A / Ctrl+C | テキストを全選択／コピー |
| 編集可能な文字入力欄 | Ctrl+X / Ctrl+V、Ctrl+Z / Ctrl+Y | テキストの切り取り／貼り付け、元に戻す／やり直す |
| 文字入力欄・プレビュー | 矢印、Home / End、Ctrl+Home / Ctrl+End、Shiftとの組合せ | カーソル移動・文字範囲の選択。プレビューは読み取り専用 |

標準操作の実装参照：[WPF ListBox](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/ListBox.cs)、[WPF TabControl](https://github.com/dotnet/wpf/blob/main/src/Microsoft.DotNet.Wpf/src/PresentationFramework/System/Windows/Controls/TabControl.cs)。

F2による名前変更、Ctrl+Lによるパス入力には、ファイル一覧用の独自割当はありません。名前変更にはShift+F6、パス入力にはヘッダーの「移動」を使います。「.ファイルを表示」の専用ショートカットもありません。

## マウス・ツール領域の操作

| 操作 | 動作 |
|---|---|
| ペイン内クリック | そのペインをアクティブにする |
| タブ見出しのドラッグ | 同じペインの別タブの左半分／右半分へ落とし、その前／後へ移動。挿入位置の線を表示。Escで中止。左右ペインをまたぐ移動は対象外 |
| Ctrl+クリック / Shift+クリック | 選択の追加・解除／範囲選択 |
| 一覧の余白を左ドラッグ | 矩形で囲んだ行を複数選択。ファイル名の右側の余白からも開始可能。端を越えてマウスを動かすとスクロール |
| Ctrl+余白ドラッグ / Shift+余白ドラッグ | 矩形内の選択を反転／既存選択に追加。ドラッグ中のEscで開始前の選択へ戻す |
| 一覧の余白をクリック | 選択解除。Ctrl/Shiftを押した場合は既存選択を維持 |
| フォルダー・ファイルのダブルクリック | フォルダーへ移動／ファイルを既定アプリで開く。実行ファイルはそのファイルのあるフォルダーをカレントディレクトリにして起動（Enterも同様） |
| 一覧の右クリック | 選択項目または背景のWindows Shellメニューを開く |
| ← / → / ↑ / ↻ ボタン | 履歴を戻る／進む、親フォルダーへ移動、更新。↑ボタンとキーボードの↑は別 |
| ヘッダーの「移動」 | 現在パスを初期表示する入力画面を開く。ローカル・UNCの絶対パスに対応 |
| ＋ / タブの× | タブ追加／そのタブを閉じる。最後の1枚は維持 |
| カラム / 列ヘッダー | 表示列・順序・幅の設定／ソート切替 |
| フィルター / 表示オプション | 名前フィルター入力／表示項目のチェックリストを開く |
| 設定 | 表示などの設定画面を開く |
| お気に入りの＋ / 項目クリック | 現在フォルダーを登録／アクティブペインで開き、読み込み後に一覧へフォーカスを移す |
| ファイル名・アイコンからドラッグ＆ドロップ | 複数選択済みなら選択項目をまとめて転送。通常は同じドライブ・UNC共有内なら移動、異なるルートならコピー。Ctrlでコピー、Shiftで移動。AltまたはCtrl+Shiftは対応外 |
| タブをお気に入りへドラッグ＆ドロップ | タブのフォルダーをお気に入りへ登録 |

詳細一覧は名前列に残り幅を使い、表示列・順序・幅を左右独立に保存します。名前列の固定幅も選べます。ヘッダードラッグの完了時には操作した側だけへ保存し、ソートはタブ内で維持します。各ペインの実際の表示幅に収まらない列は、更新日時・サイズ・File Age・種類の順で一時的に省略します。手動指定した名前列の幅を優先し、幅が増えたり縦スクロールバーが消えたりして余裕ができると列を戻します。保存した表示設定は維持します。
詳細一覧のみを提供します。旧ColumnsModeは読み込み時に無視し、次回保存から省略します。

## 対応範囲と制限

UNCは `\\server\share\folder` の形式に対応し、現在のWindowsユーザーのアクセス権を使用します。サーバー名だけの共有一覧や専用の認証画面、デバイスパスには対応していません。

ごみ箱操作は検証済みのローカル固定NTFSに限定し、UNCやリンクを含む対象などでは拒否します。完全削除へ自動で切り替えることはありません。リンクのコピー・移動・明示的な完全削除はリンク本体を扱います。リンクを含むShellコピー・切り取り・貼り付けには制限があります。圧縮等のShell拡張は選択したコマンドを実行し、リンクの扱いは各拡張の仕様に従います。

F1・F2・F9は未実装です。長時間安定性、すべてのShell拡張との互換性、Default描画方式の実表示は全面的な検証を完了していません。

## リポジトリの構成

- `src/`: アプリと共通処理
- `tests/`: 自動テスト
- `tools/`: 開発・診断ツール
- [docs/spec/](docs/spec/README.md): 要件・設計の記録（現在の操作方法はこのREADMEを参照）

ローカルの配布用バイナリ、個別環境の調査報告、スクリーンショット、実行ログ、テスト結果、個人設定はGitの管理対象外です。過去の仕様書や診断ツールに記載された証跡のパスは、公開リポジトリに含まれない場合があります。

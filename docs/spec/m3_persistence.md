# M3の実装・保存仕様

描画方式の既定値はユーザーの最新指示によりSoftwareOnly。以前の描画比較での「製品既定値は維持」という判断を更新する。実GUI品質の受入は保留する。

## 保存ファイル

通常の保存先は `%LOCALAPPDATA%/PaneCommander/`。

| ファイル | 内容 | 保存時点 |
| --- | --- | --- |
| settings.json | 描画方式、M2表示設定、サイドバーの表示状態 | 設定保存、列幅変更、サイドバー表示切替 |
| favorites.json | ID、表示名、フォルダパス、順序 | お気に入りの登録・解除・名前変更・並べ替え |
| session.json | 左右のタブ順・パス・選択タブ・ソート、アクティブ側、ウィンドウ配置・最大化状態、ペイン比率、サイドバー幅 | 正常終了時 |

描画方式は `"RenderingMode":"SoftwareOnly"` または `"RenderingMode":"Default"`。項目のない旧settings.jsonもSoftwareOnlyを使用する。設定画面の変更を保存しても、稼働中の描画方式は変えず、次回起動のWindow生成前に適用する。

お気に入りの名前変更は表示名だけを変更する。解除は登録の削除であり、フォルダを削除しない。同じパスを異なる表示名で登録できる。クリックまたは一覧でEnterを押すと、その時点のアクティブペインの選択タブへ移動する。Ctrl+Dは現在フォルダの登録。

session/favoritesはVersion=1。2026-10-17以降は詳細一覧のみ。旧タブのColumnsModeは未知プロパティとして読み飛ばし、次回正常保存では出力しない（Version=1を維持）。他のタブ・パス・選択index・ソート・配置、別ファイルの列設定とお気に入りは維持する。SelectedIndexは0始まり。ActiveSideは0=左、1=右。ウィンドウ座標・寸法はWPFのDIP、LeftPaneFractionは左右一覧領域内の比率。表示設定はsettings.jsonを正本とし、session.jsonに重複保存しない。履歴・行選択・ファイル内容は今回のセッション保存対象外。

## 復元と異常時

非選択タブはパス等の状態だけを復元し、フォルダ列挙と描画は選択時に行う。選択中の左右2タブを非同期で読込。タブ数に応じてFolderViewを増やさず、既存の左右2ビューを共有する。既存の非選択タブ一覧キャッシュ上限も維持する。

存在しない／アクセス不能な復元パスは、そのタブのパスを残してエラーを表示する。別フォルダへの黙った置換を行わず、「移動」で修正できる。未選択タブの無効パスは初回選択時にエラーとなる。お気に入り先の移動失敗では、現在フォルダを維持してエラーを表示する。

破損JSON、不明Version、範囲外の状態は理由を画面上部に表示して既定状態へ復帰。画面外の復元配置は現在の画面領域へ戻す。複数モニターと異DPIの実操作は人による確認待ち。

書込み・ディスク同期・原子的置換はUIスレッド外で実行する。お気に入りは保存成功後に表示コレクションへ反映し、失敗時は現在の一覧を保持する。終了時は進行中の設定／お気に入り保存を待ってセッションを保存する。保存失敗では理由を表示し、ウィンドウを残して再試行可能にする。

安全上限はsettings.json 64KiB、session/favorites各1MiB、各ペイン256タブ、お気に入り256件。上限超過は読込・保存とも拒否し、黙って切り捨てない。session/favoritesの置換時は直前の内容を1世代の`.bak`へ保持する。異常終了・強制終了・OSシャットダウンでの完全保存は保証しない。常駐タイマーやアイドル中の保存は追加しない。

## 検証用起動

`--profile-directory <絶対パス>`で設定・状態・ログの保存先を隔離できる。`--diagnostics-directory <絶対パス>`は明示的な検証用で、起動前の描画指定、復元結果、可視ビュー数、GC情報を記録する。10秒のウォームアップ後は名前付きイベントで終了要求を待ち、通常の終了保存経路で閉じる。通常起動には診断待機・監視タイマーを追加しない。

`--diagnostics-workload visit-tabs`は各タブを一度選択して元の選択へ戻す専用ドライバー操作。実マウス／キー操作とは区別して報告する。

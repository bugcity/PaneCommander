# フィルター一致箇所強調の要求要約

正本は2026-10-14のユーザーチャット「PaneCommander — インクリメンタルフィルターの一致箇所強調表示」。以下は要約。

- 現在取得済みの名前一覧を、大小文字を区別しないリテラル部分一致で絞る。正規表現・先頭限定・再帰検索を使わない。
- 「フィルター」または `/` で入力し、リアルタイム更新。Enterで条件を保って一覧へ、Escで解除。左右を独立させる。
- 元の名前を維持し、すべての一致部分だけを文字色と太字で強調する。背景・選択・File Ageは維持する。
- 強調色は既存配色と「カラー」設定で扱い、Viewにカラーコードを埋め込まない。ダーク／ライト・選択行でも読みやすくする。
- 入力追加・削除・0件・空条件・左右・タブ切替・解除を検証し、不要な選択／スクロール／フォーカス変更をしない。
- 仮想化とコンテナ再利用を維持し、表示行だけに必要な描画要素を作る。全タブのVisual更新、非表示タブ用UI、常駐タイマー、不要な再列挙を追加しない。
- 単体・回帰・実画面・大量件数・再列挙防止・既存キー操作を検証する。
- 未使用、少数／多数一致、連続入力削除、開始解除反復、6タブのPrivate Bytes・Working Set・CPU・生成行数を変更前後で比較する。
- 強制GCで数値を改善しない。数値の悪化は未達、未検証は未検証として報告する。機能と性能の受入は別判定する。

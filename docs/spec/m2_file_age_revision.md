# M2 日時表示修正（ユーザー指示、2026-10-12）

One CommanderのFile Age表示を基準とし、従来の独自の時間区分と色分け仕様は破棄する。

1. 最終更新日時から現在までの経過時間をFile Ageとして表示。
2. 分・時間・日・月・年の短縮形式。
3. 新しいファイルを赤系、古いファイルを青系とする連続的な色変化。
4. 1時間・1日・7日等の固定区分による段階色を使用しない。
5. File Ageと絶対更新日時は独立した表示項目。
6. 色表示の有効・無効、彩度・明度を設定可能。
7. 一覧再表示・フォルダ移動・タブ切替時に再計算。
8. 日時表示専用の常時稼働タイマーは禁止。
9. 厳密な対応式は公開情報では確定できないため、One Commanderを参照し、未確認部分を報告。

受入条件：新しいほど暖色・古いほど寒色、色の連続変化、両列の併記、設定反映、不要なCPU負荷・メモリ消費を増やさない。
人によるGUI確認完了まで受入完了としない既存条件を継承する。

## 後続指示と了承

File Ageは添付453045.jpgを参照し、経過時間の色を背景色として表示する。種類欄のディレクトリは[DIR]と表示。性能試験は画面案を提示し、ユーザー了承後に行う。2026-10-12、[DIR]表示を含む画面に対して「デザインはOK」と明示了承を得た。

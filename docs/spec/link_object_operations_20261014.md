# リンク本体操作の仕様記録

2026-10-14のユーザー指示の要約。正本は同日のチャット指示。以前のWindows Shellによる内容コピー方針を置換する。

| 操作 | ジャンクション・ディレクトリ／ファイルシンボリックリンク |
|---|---|
| Enter | 参照先のディレクトリ／ファイルを開く |
| F5／コピーDnD | 同じ種類・ターゲットのリンク本体を複製する |
| F6／移動DnD | リンク本体を移動する |
| F8 | 確認後、リンク本体を完全削除する |

- 相対ターゲットは文字列を維持する。コピー先では解決先が変わり得ることを明示し、勝手に絶対指定へ変更しない。
- 通常ディレクトリの再帰コピー・削除でもリンク先へ進入しない。複数階層・循環・リンク切れを安全に扱う。
- 再解析タグとディレクトリ属性を識別する。未知タグを普通のディレクトリとして再帰しない。
- 複製できない場合は権限・OS・FS等の原因を正確に通知する。参照先内容コピーへの代替は禁止。
- ボリューム間移動で複製後削除が必要なら、リンク本体の複製成功・検証後に元を削除する。
- F5/F6/F8と内部DnDは共通基盤を使用する。外部Shellの動作はアプリが制御できるものとして報告しない。
- リンクの種類・ターゲット・存在と、参照先の内容・状態を別々に検証する。通常項目の回帰、複数選択、失敗時の安全性も検査する。
- Release・自動試験と実GUI試験を区別する。未検証を合格・完了扱いしない。

実装方式・対応状況・未対応範囲は [検証報告](../../LINK_OBJECT_OPERATIONS_REPORT.md) に記録する。

# DnD宛先確定仕様（2026-10-16）

根拠: ユーザー「ドラッグ＆ドロップの宛先仕様確定と実装・検証」。V15等の以前の「フォルダーへドロップ」を置き換える。

- 宛先は受け取ったペインのアクティブタブの現在ディレクトリのみ。空白・通常ファイル・EXE・スクリプト・ショートカット・ディレクトリの行で同じ。
- 行のDataContext、HitTest、リンクターゲットを宛先に使用しない。行へShell Dropを委譲しない。
- DnDによる起動・関連付け実行・引数渡し・コマンド実行なし。
- Ctrlコピー／Shift移動／既存の同一ボリューム移動規則を維持。Alt、Ctrl+Shiftのリンク操作は提供しない。
- 同一ディレクトリへの移動は安全なno-op。同一ディレクトリ内のDnDコピーも別名を暗黙生成せず拒否。明示的コピー／名前変更ダイアログの動作は変更しない。
- 非アクティブタブへのホバーでは切替えない。タブ宛先機能は追加しない。
- ExplorerからのCF_HDROPも同じ受信処理。Explorerへ送信する既存形式とリンク安全制限を維持。
- 共通ファイル操作基盤の競合・エラー・cancel・後始末・一覧更新を使用する。
- 以前の同一ペインでフォルダー内へ移動しなかった観測は保存。当時の期待と今回の期待を区別し、新仕様の成立を自動的に合格にしない。

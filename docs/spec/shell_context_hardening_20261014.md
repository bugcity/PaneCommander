# Shellコンテキストメニュー改修の現行要求

2026-10-14のユーザー指示。以前の「確認後に完全削除」を置き換える。

- F8/Delete/右クリック削除はごみ箱。Shift+Deleteは確認後に完全削除。ごみ箱が使えない場合は無断で永久削除に変更しない。
- 背景メニューのハンドル種類・発生経路・所有関係を調査し、最小API・取得のみ・実ポップアップを別に測定する。
- 原因に対する最小修正と同条件比較。強制GCや呼び出し回数削減で隠さない。拡張・OS設定を無断変更しない。
- Shellリンクcopy/cut/pasteは安全性確認まで制限を維持。参照先へフォールバックしない。
- 更新は自操作・移動・必要再表示・明示更新。常時監視・ポーリングを追加しない。一括操作後にまとめて更新。
- 機能・実GUI・安全性・性能・回帰を独立判定し、証跡のない項目を合格にしない。

現行の結果はルートのSHELL_CONTEXT_IMPLEMENTATION_REPORT.md、SHELL_CONTEXT_CAUSE_REPORT.md、SHELL_CONTEXT_PERFORMANCE_REPORT.mdを参照。

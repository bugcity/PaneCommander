# 2026-10-17 確定仕様

根拠: ユーザー確認回答「この仕様で確定する」「種類、File Age、サイズ、更新日時」。

- Shift+F5: 選択項目を同じフォルダーへコピー。名前を明示指定し、暗黙別名生成なし。複数選択では各項目の名前を入力し、全入力確定後に実行。キャンセル時は実行開始しない。
- Shift+F6: 単一選択項目の同じフォルダー内での名前変更。複数選択時は無効。
- Shift+F8: 未割当てを維持。Shift+Deleteへ流用しない。
- 一覧以外・文字編集中・Shellメニュー中・操作中はこれらを起動しない。
- 狭幅では名前を残し、種類→File Age→サイズ→更新日時の優先順で表示する。省略は逆順。広がれば復帰。ユーザーが非表示にした列は復帰させない。名前を明示非表示にしている既存設定も維持する。
- 自動省略でJSONの列順・表示指定・列幅を書き換えない。名前列に残り幅を割り当てる設定を維持し、固定幅の場合は利用幅に収める。

実装・受入状態はFUNCTIONAL_GAP_INVENTORY.mdおよびdocs/verification/functional-acceptance-20261017/REPORT.md。

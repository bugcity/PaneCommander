# Windows Shellコンテキストメニュー 要求と境界

要求正本は2026-10-14のユーザー本文「Windows標準コンテキストメニューへの対応」。実装／検証状況は `SHELL_CONTEXT_IMPLEMENTATION_REPORT.md` を参照する。

正式なShell COMインターフェースから動的に取得し、Windows 11で従来形式を許容。詳細／階層一覧で選択、複数選択、背景、Shift+F10、Apps、Escとフォーカスを扱う。未確認のリンク破壊操作はShellへ委譲しない。常駐タイマー・監視を増やさず、仮想化を維持。性能・安全性・Shell互換性・実画面を個別に判定する。

削除は既にユーザーが指定した確認後の完全削除を維持。リンクの複製・移動・削除は共通のリンク保護方針を維持し、Shellのコピー／切り取り／貼り付けで異なる処理へフォールバックしない。メニューの見た目がWindowsであることと、独自の操作サービスを経由するdelete/renameを区別して報告する。
